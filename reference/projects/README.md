# تصاویر مرجع طراحی صفحهٔ پروژهها

تصاویر پیوستشدهٔ این مرحله که به عنوان مرجع طراحی `projects.html` استفاده شدهاند.
آنها را تغییر ندهید؛ خروجی نهایی در `assets/images/projects-card.jpg` و
پیشنمایشهای رندرشده در همین پوشه قرار دارد.

| فایل | ابعاد | مربوط به |
| --- | --- | --- |
| `projects.png` | 1293×2951 | نمای کامل صفحهٔ پروژهها در حالت دسکتاپ |
| `image-1.png` | 1123×287 | نوار سرمهای هیرو: «همه پروژهها، یک استاندارد ساخت» + شمارندهٔ ‎+۱۰۰ |
| `image-2.png` | 1120×215 | نوار فیلتر: جستجو، دستهبندی، دکمههای فضا و سه select |
| `image-3.png` | 844×502 | جدول ۳×۲ کارتهای پروژه |
| `image-4.png` | 1021×394 | نوار «چرا لایکودیزاین؟» (مشترک با صفحهٔ خدمات) |
| `image-5.png` | 1017×430 | فرم «چطور میتوانیم به شما کمک کنیم؟» (مشترک با صفحهٔ خدمات) |

پیشنمایش رندرشده: `preview-desktop.jpg` (۱۴۴۰px)، `preview-tablet.jpg` (۷۶۸px)
و `preview-mobile.jpg` (۳۶۰px) — خروجی مرورگر headless.

بازتولید تصویر کارت:

```bash
python3 -m pip install pillow
python3 tools/extract-project-images.py
```

> نکته: در `image-3.png` هر ۶ کارت از یک عکس نمونه (مجتمع تجاری در شب) استفاده
> کردهاند. در پیادهسازی نهایی همان عکس تمیز برای کارت «مجتمع تجاری آفتاب» و
> عکسهای واقعی پروژههای موجود قالب برای ۵ کارت دیگر به کار رفته است تا آرشیو
> قابل استفاده باشد؛ طراحی کارتها (اورلی، دکمهٔ «مشاهده پروژه»، عنوان و متراژ)
> دقیقاً مطابق تصویر مرجع است.
