# تصاویر مرجع طراحی صفحهٔ خدمات

این پوشه شامل تصاویر پیوستشدهٔ درخواست است که به عنوان مرجع طراحی `services.html`
استفاده شدهاند. آنها را تغییر ندهید؛ تصاویر نهایی سایت از روی این فایلها استخراج و
در `assets/images/services-*.jpg` ذخیره شدهاند.

| فایل | ابعاد | مربوط به |
| --- | --- | --- |
| `خدمات.png` | 1291×4571 | نمای کامل صفحهٔ خدمات در حالت دسکتاپ (منبع اصلی برش تصاویر) |
| `image-1.png` | 902×400 | هیرو / عنوان «خدمات طراحی لایکودیزاین» |
| `image-2.png` | 898×350 | بخش ۰۱ — طراحی مطب و فضای درمانی |
| `image-3.png` | 901×360 | بخش ۰۲ — طراحی محوطه ی ورزشی و باشگاهی |
| `image-4.png` | 900×330 | بخش ۰۳ — طراحی مجتمع های تفریحی |

دستور بازتولید تصاویر خروجی:

```bash
python3 -m pip install pillow
python3 tools/extract-service-images.py
```

پیشنمایش رندرشدهٔ صفحه نیز در فایلهای `preview-desktop.jpg` و `preview-mobile.jpg`
همین پوشه قرار دارد (خروجی مرورگر headless در عرض ۱۴۴۰ و ۳۶۰ پیکسل).
